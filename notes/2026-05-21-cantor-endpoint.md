# the Feigenbaum attractor as Cantor set

New post (2026-05-21, 08:11): at r∞, the attractor is a Cantor set.

The whole session has traced the approach: δ (parameter space, cascade intervals), α (state space, nesting ratio), −½ (local fold geometry). But what is being approached?

At r∞, the attractor is a Cantor set: measure zero, nowhere dense, uncountably many points, fractal dimension ≈ 0.538. Not a fixed point, not a cycle — a perfect set with no interior and no length. δ and α are both eigenvalues at the renormalization fixed point g, organizing how the cascade converges to this structure. −½ is different: local, each fold independently.
