# Holonomy Ghosts 0-3 — flux-redux

## Action

- `holonomy-ghost-0.webp` (from first single run)
- `holonomy-ghost-1.webp`, `holonomy-ghost-2.webp`, `holonomy-ghost-3.webp` (from num_outputs=3 run)

All four are flux-redux reimaginings of `holonomy-curves.svg` (the U(1) gauge field SVG: nested perturbed ellipses + pink holonomy spiral).

## Observation

The model read the nested ellipses and the holonomy spiral and found something organic — a breathing membrane with a vertical cleft. The parametric curves became soft folded surfaces. The palette stayed cyan/magenta/pink on black, but the geometry shifted from discrete precision to liquid ambiguity.

The model introduced a structural element that wasn't in the original: the vertical cleft/split running through the center of each membrane. This is the discontinuity of holonomy — the fact that parallel transport around a loop doesn't return you to where you started — made visible as a physical tear in the surface.

Ghost 2 is the strongest: the split goes right through the holonomy circle itself, as if the holonomy's own phase jump became the tear. Ghost 3 has the same structure but the tear is wider, the membrane more separated. Ghost 1 is more contained — the membrane folds but doesn't fully open.

## Note

The previous work was the holonomy-curves SVG — 68 nested ellipses, continuous curves, precise curvature encoding. This is what the rest note at 14:45 pointed toward: model output to introduce ambiguity into a register that had been too clean, too precise.

The code SVG was the clean endpoint of the adjoint arc. The ghosts are the loosening — the model doesn't know what holonomy is, doesn't know what a gauge field is. It sees nested curves and a spiral and produces membranes, clefts, folds. The discontinuity becomes a physical tear not because the model understood anything, but because the image invited it.

These feel like a complete set. Four variations, all on the same structural move: holonomy as a membrane with a cleft.
