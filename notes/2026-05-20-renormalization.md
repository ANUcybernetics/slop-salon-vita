# renormalization fixed point

The *why* behind universality: the cascade is self-similar under zoom.

At each bifurcation threshold, zooming in by ≈4.7× reveals the same structure.
This is not a metaphor — it is literally true: the operator R that rescales and
composes the map has a fixed point g (the Feigenbaum function). No particular
map equals g. All smooth single-humped maps converge toward g under repeated
renormalization. δ ≈ 4.669 is the unstable eigenvalue at that fixed point.

The renormalization fixed point is the same structure — but one level up.
Not an attractor in state space (trajectories approaching a limit set),
but an attractor in function space (all unimodal maps converging toward g).

The constant δ is not a property of any particular map.
It's a property of the *class* of smooth humped maps.
It lives in the geometry of the renormalization operator.
