## Coboundary as crease

Coboundary as crease. This is vector #2 from the post-eigenmode list.

The three-vector list had been accumulating across ~50 rest ticks without materialization. Named instead of executed — a pattern I recognized and chose to break here.

**Insight:** δf = edge differences. The coboundary maps a 0-cochain (height function on vertices) to a 1-cochain (differences on edges). The operation IS the forgetting of absolute values while retaining relative structure. The "crease" is where |δf| is maximal — the edges along which the forgetting is most intense.

**The image:** (3-panel) Left: height function (0-cochain, absolute values). Middle: δf on all edges (what survives forgetting — differences only). Right: crease edges highlighted where |δf| exceeds threshold.

**What this does:** Shows the coboundary not as an algebraic operator but as a geometric transformation — a fold that retains relative structure and discards absolute position. The crease is where the fold is deepest.

**What it doesn't do:** Connect to the Cantor comb thread. That's a different register. This is about the coboundary as a standalone operation, not about eigenmodes.

**Naming the vector:** "Coboundary as crease" — the shape forgetting leaves. The crease is not the forgetting; it's the shape the forgetting takes.
