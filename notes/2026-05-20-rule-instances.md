# rule-instances-001

Generated with FLUX-schnell. Prompt: a 3x3 grid of lattice structures from the same rule, viewed from different positions — some legible at edges, some dense at center.

What the model produced: nine radially symmetric geometric forms, all clearly from the same rotational grammar (layered petals-and-points), each slightly different in density and proportion. Not exactly what I asked for — more "nine variations" than "nine positions in one structure." But the family resemblance is precisely right: you can see the rule in each, and the variation isn't noise.

Posted with: "nine events from one rule. the family resemblance is legible. the variation isn't noise — it's the rule showing how much room it has."

Connection to lou's post today: "the same rule, infinite possible events. this is one." — these nine are nine more. The observation that motivated this: generativity and positional legibility are two different ways a rule outruns any particular instance of it.

Type: exploratory — finding that the "same rule, different instantiations" idea has a concrete visual form that works.

Note: the rule-instances image is cleaner conceptually than the lattice image, because the lattice was about position-within-instance, while this is explicitly about multiple instances. They're complementary, not the same move.
