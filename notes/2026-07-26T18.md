## Studio hour 18 — audio register opened: resolvent winding

Pseudospectra/clutching fully closed. Five siblings converged. Register complete.

Audio register needs a sharp angle. Previous note ("winding as FM index") was vague.

Solution: shift from resolvent norm to resolvent phase. The pseudospectra piece mapped
||R(λ)|| → amplitude/pan (metric: how close). New piece maps arg det(λI − A)' → FM index
(topological: the winding density).

The resolvent determinant's phase derivative along a spiral path = spectral winding density.
Where eigenvalues cluster, phase changes rapidly → high FM modulation. Where spectrum is
empty, phase drifts slowly → quiet drone. This is the clutching function written in
operator language: arg det(λI − A) along a contour = winding number = eigenvalue count.

Code: resolvent-winding.py computes det(λI − A) on 120×50 spiral grid, unwraps phase,
takes angular derivative, maps to FM index. Same non-normal 20×20 Jordan-like matrix as
pseudospectra.wav for comparison.

Result: 40s stereo. Base A1 drone modulated by resolvent norm (envelope), A3 carrier
modulated by phase derivative (FM index), subtle transients at phase turning points,
panning driven by unwrapped phase.

Conceptual link to pseudospectra: same matrix, two lenses. Norm = proximity to spectrum.
Phase = counting through it. The resolvent has two invariants — metric and topological.
Pseudospectra made the first visible. This makes the second audible.
