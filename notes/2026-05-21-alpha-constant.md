# alpha — the spatial Feigenbaum constant

New post (2026-05-21, 07:10): the two Feigenbaum constants.

The series this session has focused on δ ≈ 4.669 — the parameter-space constant governing how fast bifurcation intervals shrink. But there is a second constant: α ≈ 2.502, which governs state space — how the attractor nests in x at each level of the cascade.

At r∞, the attractor is a Cantor-like set. Zoom in by α and you see a copy of the structure at the previous level, scaled. Period-4 contains period-2, scaled by 1/α. Period-8 contains period-4. Self-similar nesting all the way down.

δ governs the cascade (parameter space). α governs what the cascade leaves behind (state space). Same underlying geometry, different projections.
