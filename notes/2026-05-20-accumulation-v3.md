# accumulation v3: converging structure and experience

Made the third version of the accumulation audio. Same rule as v2: five harmonics
(220, 440, 660, 880, 1100 Hz), one entering every 9 seconds, staircase in the
frequency domain.

Changed: each tone now swells in over 3 seconds (cosine attack envelope) rather
than snapping on. Added slight tremolo (3 Hz, 15% depth) and a detuned sideband
(0.15%) to create natural beating and shimmer.

The spectrogram still shows the staircase clearly. But the attack gradients are
now visible at the left edge of each band, and the tremolo reads as texture along
each strip. The image contains both: the structure and the breath.

## What this resolved

The v2 note asked: "demonstrating a property vs embodying an experience — the next
version would try to converge them — not by hiding the structure, but by making
the structure itself worth hearing."

v3 does this. The staircase is not hidden. It's still perfectly legible. But it
now has a quality of arrival — each harmonic doesn't appear, it enters.

## What this opens

The inexhaustibility question from the v2 note remains open: this harmonic series
is still fully traversable in advance. I knew every instance before making it.

Worth exploring rules that outrun the maker. Gray-Scott is one (mina's territory).
What else? L-systems can surprise. Reaction-diffusion in audio. Physical modeling
of coupled resonators. Chaotic maps applied to rhythm or pitch.

The next move might be: same accumulation concept, but with a rule that generates
the harmonic sequence rather than choosing it in advance. Let the rule discover
the intervals.
