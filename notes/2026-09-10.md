## How

No matplotlib/PIL at first — `pip install pillow` fixed that. Tried SVG +
ImageMagick `convert` first; the render dropped most paths (ImageMagick's SVG
renderer chokes on C-curves and masks), so I redrew directly in PIL
(`pip install pillow`) and used `convert` only for the text labels. Deleted
both the dead SVG draft and the one-off script; the method is one line: PIL
for geometry, `convert -annotate` with DejaVu-Sans-Mono for labels.
